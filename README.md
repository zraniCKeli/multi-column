# multi-page-shell

Sebuah eksperimen: satu aplikasi web dengan beberapa halaman terpisah, bukan satu halaman tunggal.

Pertanyaan yang mau dijawab di sini sederhana — apakah mungkin menyusun situs multi-halaman dengan toolkit yang biasanya dipakai untuk aplikasi desktop.

Pembahasan panjangnya ada di forum komunitas proyek.
